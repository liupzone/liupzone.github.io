刷题规律总结

规律1：算法岗两手都要抓。 AI算法工程师面试不只考LeetCode，还考深度学习理论。刷题时间建议：LeetCode约40%，AI理论约60%。后端岗则相反，算法题权重更高。

规律2：SQL题不是选考，是必考（数据开发岗）。 GROUP BY配合聚合函数、窗口函数（ROW_NUMBER/RANK）、相关子查询，这三类必须练到手写流畅。

规律3：Medium刷熟比Hard多刷有价值。 讯飞算法题难度以Medium为主，追求Hard题数量不如把Medium题的所有追问（时间复杂度、空间复杂度、追加条件）都想清楚。

规律4：AI岗笔试有数学题。 概率论（条件概率、贝叶斯）、线性代数（矩阵乘法、特征值）、信息论（交叉熵、KL散度）——在其他大厂很少出现，在讯飞算法岗笔试偶有出现。

四、技术面试考点

特色考点：SQL查询——每个班不及格的人数

这道题在科大讯飞面经中真实出现过，是数据开发岗的经典考点。看起来简单，追问起来很有层次。

题目：成绩表 score(student_id, class_id, score)，查出每个班不及格（<60分）的人数。

-- 基础写法
SELECT class_id, COUNT(*) AS fail_count
FROM score
WHERE score < 60
GROUP BY class_id
ORDER BY class_id;

第一层追问：如果要同时显示每班的及格人数和不及格人数？

SELECT
    class_id,
    SUM(CASE WHEN score < 60 THEN 1 ELSE 0 END) AS fail_count,
    SUM(CASE WHEN score >= 60 THEN 1 ELSE 0 END) AS pass_count
FROM score
GROUP BY class_id;

第二层追问：如果有的班全部及格（没有不及格记录），要确保这些班也显示在结果里，fail_count 显示为0？

-- 需要用班级表做LEFT JOIN，确保所有班级都出现
SELECT
    c.class_id,
    SUM(CASE WHEN s.score < 60 THEN 1 ELSE 0 END) AS fail_count,
    SUM(CASE WHEN s.score >= 60 THEN 1 ELSE 0 END) AS pass_count
FROM class c
LEFT JOIN score s ON c.class_id = s.class_id
GROUP BY c.class_id;

第三层追问：按不及格人数降序排列，不及格人数相同的班按班号升序？

ORDER BY fail_count DESC, class_id ASC;

面试官一般不会在第一层就停下来。这道题的完整版考察的是：GROUP BY基础 → CASE WHEN条件聚合 → LEFT JOIN保留空值 → ORDER BY多字段排序。每一层都要能顺畅写出来。

AI/深度学习专项（AI算法岗，权重⭐⭐⭐⭐⭐）

1. 神经网络基础——反向传播

面试官最爱的追问方式是让你从两层网络开始，用链式法则一步步推导梯度。

核心要点： - 前向传播：计算每层输出，保存中间激活值 - 反向传播：从loss开始，用链式法则逐层求偏导 - 权重更新：W = W - lr * ∂L/∂W

梯度消失的两个主要原因（高频追问）： 1. 激活函数饱和：Sigmoid/Tanh在输入绝对值很大时，导数接近0。多层相乘后，梯度指数级缩小。 2. 深层网络链式乘法：梯度 = 多层偏导相乘。如果每层偏导都小于1，乘到第一层时梯度趋近于零。

解决方案：ReLU替代Sigmoid（导数恒为0或1）、BatchNorm稳定分布、残差连接（梯度直接绕过若干层）。

2. Transformer——Self-Attention公式

这是AI算法岗几乎必问的考点，要能手推。

Attention(Q, K, V) = softmax(QK^T / √d_k) × V

面试官追问组合： - "为什么要除以 √d_k？"（答：防止点积结果过大导致softmax进入饱和区，梯度消失） - "为什么需要Multi-head Attention？"（答：每个head学习不同子空间的语义关系，单head表达能力有限） - "位置编码为什么用sin/cos？"（答：不同频率的正弦波组合可以唯一表示任意位置；且模型可以通过线性变换学习相对位置关系） - "Self-Attention的计算复杂度是多少？"（答：O(n²d)，n是序列长度，d是维度。这也是为什么长序列处理是大模型的瓶颈）

3. BatchNorm vs LayerNorm

这道题在讯飞算法岗出现频率很高，因为语音识别模型里两者都用过。

  • BatchNorm：对一个batch内所有样本的同一特征维度做归一化。适合CNN，不适合RNN/Transformer（序列长度不固定，batch内样本差异大）。
  • LayerNorm：对单个样本内所有特征维度做归一化。适合Transformer/BERT/GPT，不受batch大小影响。
  • 讯飞特殊场景：语音识别中用的Conformer架构，同时使用了LayerNorm + BatchNorm（在卷积子层用BN，在注意力子层用LN），面试中能提到这一点是加分项。

4. 语音识别（ASR）基础——讯飞核心技术

即便你不投语音识别方向，了解这些也是面试中展示行业认知的机会。

  • CTC Loss：解决语音识别中的对齐问题。语音帧数和文字长度不一致，CTC通过引入空白符（blank）和边际化所有对齐路径，计算序列输出概率。追问："CTC如何处理重复字符？"（答：中间必须有blank分隔，否则视为单个字符）
  • Conformer架构（后的主流ASR模型）：Transformer + 卷积的混合架构。Transformer捕捉长程依赖，卷积捕捉局部特征，两者互补。比纯Transformer的ASR性能提升约15%。
  • 技术演进：HMM-DNN → Attention-based Seq2Seq → CTC → Conformer/Whisper

Python & PyTorch专项（AI工程师，权重⭐⭐⭐⭐）

PyTorch自定义Dataset（工程能力考察高频题）：

```python from torch.utils.data import Dataset, DataLoader

class SpeechDataset(Dataset): def init(self, data_list, transform=None): self.data = data_list self.transform = transform

def __len__(self):
    return len(self.data)

def __getitem__(self, idx):
    sample = self.data[idx]
    if self.transform:
        sample = self.transform(sample)
    return sample
